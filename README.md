# Aviation Weather Hazard Check — single-file version

Author: © Simon Z. Chan  
Updated: 2026-11-11 12:25 EST


`index.html` is the whole page in one file. Upload it to any GitHub repository, GitHub Pages,
Cloudflare Pages (as a static site) or any web host, or just open it from your computer.

- Check up to 4 locations at once: city, airport name, or ICAO/IATA/FAA code.
- The location list and text size are kept in the address, e.g.
  `index.html?loc=KJFK&loc=Heathrow&loc=Denver,%20CO&text=125`, so a bookmark remembers them.

## Data relay

aviationweather.gov and MeteoAlarm block direct requests from browsers on other sites, so this file
sends those requests (and airport name search) through the published Aviation WX Check server:

    <script>window.__API_BASE__ = 'https://aviation-wx-check.pplx.app/port/8000';</script>

To use your own relay instead, change that line. For the Cloudflare Pages edition use
`https://<your-project>.pages.dev/api`. Everything else (NWS, Environment Canada, Open-Meteo,
BigDataCloud) is fetched directly by the browser. No API keys, no stored data.

Generated by `tools/build_web.py`; edit `public/index.html` in the main repository, not this file.
Not an official briefing source; always get a full briefing before flight.
